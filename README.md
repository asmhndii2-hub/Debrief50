# Debrief50

A simplified exam-only copy of DebriefRoom.

## Included exams
- Communications: fixed 50-question supplied paper
- Air Law: fixed 50-question supplied paper

The original 964-question bank is not loaded by the interface.

## Behaviour
- Original question order and A-D choices
- No feedback until submission
- Previous/Next navigation with answer persistence
- Unanswered-question warning and confirmation
- Results with incorrect-answer review
