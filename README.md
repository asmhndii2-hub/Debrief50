# Debrief50

A mobile-first fixed-exam website for supplied 50-question aviation papers.

## Included exams

- Communications — 50 questions — pass mark 75%
- Air Law — 50 questions — pass mark 75%
- Operational Procedures — 50 questions — pass mark 80%

Each new attempt shuffles the order of complete question records. Answer choices remain in their original A/B/C/D order, and each correct-answer key stays attached to its own question.
